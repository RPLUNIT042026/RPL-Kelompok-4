## Cara Kerja Tim

- **Metode:** Agile Scrum, sprint mingguan.
- **Acara Scrum:** Sprint Planning (awal sprint), pertemuan singkat rutin, Sprint Review dan Retrospektif (akhir sprint).
- **Pelacakan tugas:** GitHub Issues dan GitHub Projects (kolom *To Do, Doing, Review, Done*).
- **Kolaborasi kode:** cabang `main` (stabil), `dev`, dan `feature/*`; perubahan masuk lewat Pull Request yang ditinjau minimal satu anggota lain.
- **Saluran komunikasi:** [ WhatsApp]

## Definition of Done (usulan awal)

Sebuah tugas dianggap selesai bila:
1. Fungsinya berjalan sesuai kriteria penerimaan di Issue.
2. Sudah di-*commit* dan di-*push* ke GitHub lewat Pull Request.
3. Sudah ditinjau minimal satu anggota lain.
4. Tidak merusak fitur yang sudah ada.
5. Dokumentasi singkat diperbarui bila perlu.

## Komitmen Kelompok

- Setiap anggota berkontribusi lewat commit atas nama sendiri di setiap sprint.
- Hambatan disampaikan sedini mungkin kepada Scrum Master.
- Keputusan prioritas fitur berada pada Product Owner, setelah diskusi tim.
